Git is a distributed version control system used to track changes in source code.



\### Common Commands

git status

git branch

git branch <branch-name>

git switch <branch-name>

git switch -c <branch-name>

git add .

git commit -m "<message>"

git log --oneline

git remote -v

git diff

git push

git pull

git clone <repository-url>



\### Workflow

Working Directory -> git add -> Staging Area -> git commit -> Local Repository -> git push -> Remote Repository



\### Branching

Branches allow developers to work on features or fixes independently and merge changes into another branch when ready.



\### Troubleshooting

1\. Check git status.

2\. Check the current branch.

3\. Check configured remotes.

4\. Inspect git diff.

5\. Review recent commits.

6\. Check whether the remote branch is ahead or behind.



\### Safety

git reset, git clean, and force pushing can cause data loss or overwrite history. An automated DevOps assistant should require explicit approval.
